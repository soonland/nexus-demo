# nexus-demo

A deliberately tiny project (a `slugify` helper with tests) used to show the
[nexus](https://github.com/soonland/nexus-marketplace) Claude Code plugin working on a real repo.

Look at the closed issues and merged pull requests to see what each step produced:

1. `nexus:setup` and `nexus:repo-standards` added CI, Dependabot, issue templates, commit tooling and a `CLAUDE.md`.
2. `nexus:feature-spec` turned a one-line idea into a spec issue.
3. `nexus:implement-feature` planned, coded, tested and opened the PR.

```
npm ci
npm test
```
